## Major Projects

### Project 1: Student Career Predictor (Days 41–50)
A machine learning classification model that predicts a student's probable career path (STEM, Arts, Business) based on their subject preferences, interests, and grades.

**Tech Stack:**
- Scikit-learn
- Pandas for preprocessing
- Matplotlib and Seaborn for data visualization
- Streamlit for UI deployment

---

### Capstone Project: Skin Disease Classification System (Days 90–100)
A deep learning image classifier designed to detect common skin diseases such as eczema, fungal infections, or psoriasis from raw image input.

**Tech Stack:**
- TensorFlow / PyTorch
- Convolutional Neural Networks (CNNs)
- Grad-CAM visualizations
- Flask + Docker for deployment
- Trained on publicly available medical image datasets
